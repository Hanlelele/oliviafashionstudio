E-Commerce: Olivia Fashion Studio

🚀 Tech Stack

Frontend: ReactJS, Vite, React Redux, Redux Toolkit, Material-UI, Tailwind CSS

Backend: Node.js (Express), MongoDB

Authentication: JWT, Google OAuth

API: RESTful APIs

📌 Features

🌐 User Interface

Developed a fully responsive and user-friendly UI using ReactJS and Tailwind CSS.

Modern design with Material-UI components.

🔐 Authentication

User sign-up and sign-in with email and password.

Google OAuth integration for seamless login.

Access token management and login state persistence.

Role-based access control for admin and users.

🛒 Cart & Checkout

Add, remove, and update items in the shopping cart.

Apply discount coupons at checkout.

Secure payment integration using PayPal.

📦 Order Management

View and update order status in real-time.

Track orders and manage transactions.

🛠 Admin Dashboard

Product Management: Create, read, update, and delete (CRUD) products.

Image Upload: Upload product images with a preview feature.

Analytics: Revenue analysis and product performance insights.

📂 Project Setup

1️⃣ Clone the Repository

git clone https://github.com/Hanlelele/oliviafashionstudio.git

2️⃣ Install Dependencies

Backend

cd backend
npm install

Frontend

cd frontend
npm install

3️⃣ Run the Application

Start Backend

cd backend
npm start

Start Frontend

cd frontend
npm run dev

The application will be available at http://localhost:5173
